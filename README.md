# U Compile

**U Compile** is a simple code compiler that allows users to write, compile, and run code directly from the application.

It currently supports **JavaScript, C++, and Python**, and provides compilation/runtime output along with error messages to help users identify and fix problems.

## ✨ Features

- 🧑‍💻 Write code directly in the editor
- ⚡ Compile and run code
- 🐍 Python support
- ⚙️ C++ support
- 🟨 JavaScript support
- ❌ Displays compilation and runtime errors
- 📤 Shows program output
- 🎯 Simple and beginner-friendly interface

## 🛠️ Supported Languages

| Language | Supported |
|----------|-----------|
